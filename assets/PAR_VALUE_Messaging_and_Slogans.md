# Par Value — Messaging & Slogans

*Last updated: June 24, 2026*

A reference for the lines we use across the brand, where each belongs, and how to format them consistently.

---

## Website Headline

> **The market sets the price. We set the standard.**

The lead line on **getparvalue.com**. Captures the core promise: an independent, fair-market value engine plus a trusted standard for golfer-to-golfer trading.

---

## Signature Slogan

> **Buy Fair. Sell Smart. Play On.**

The primary tagline and the line currently featured on the launch graphic. Each beat does real work:

- *Buy Fair* — the fair-market value ("Par meter") promise
- *Sell Smart* — the seller-side value pitch
- *Play On* — golf identity, without the cliché

**Formatting (canonical):**
- Punctuation: **periods**, not commas (each phrase gets its own visual beat; photographs better on cards).
- Capitalization: **Title Case** for lockups and logo treatments — `Buy Fair. Sell Smart. Play On.`
- On graphics it may be set as **tracked uppercase** with center dots — `BUY FAIR · SELL SMART · PLAY ON`.
- Keep one canonical version so it doesn't drift across surfaces.

---

## Supporting / Campaign Lines

Secondary lines for posts, ads, and rotation. Use one at a time; don't stack multiple slogans on a single asset.

- **Your bag's worth more here.** — punchy, benefit-led; strong for value-focused posts.
- **Where golfers trade like golfers.** — peer-to-peer identity; strong for bios and "what we are" messaging.

## Usage Notes

- **Headline vs. slogan:** the website leads with the headline; social/launch assets lead with the wordmark and the signature slogan.
- **One slogan per asset.** Avoid competing lines in a single graphic.
- **Voice:** confident, plain-spoken, trust-forward. Financial credibility + golfer authenticity. Avoid hype and avoid golf-pun overload (use puns sparingly, if at all).
